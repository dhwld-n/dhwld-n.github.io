소개

부산대학교 정보컴퓨터공학부 인공지능전공에 재학 중입니다 (2025.3 ~). LLM을 코드·하드웨어·CI 같은 실제 엔지니어링 파이프라인에 연결하는 데 관심이 많습니다.

agent_with_gpt 프로젝트에서는 git push 한 번에 워크로드 특성을 분석해 테스트 보드를 고르고, 실행·회귀 판정·보고서 작성까지 이어지는 자동화 에이전트를 만들었습니다. "판단은 코드로 검증 가능하게, 서술은 LLM에게"라는 원칙 아래, 믿고 맡길 수 있는 에이전트를 설계하는 일을 하고 싶습니다.

  • LLM / OpenAI API
  • LLM Agent / Function Calling
  • Python
  • CI 자동화 (GitHub Actions)
  • Flask
  • Notion API

프로젝트

agent_with_gpt — 타겟 보드 자동화 에이전트

git push가 들어오면 LLM 에이전트가 커밋과 테스트 코드를 읽어 워크로드 특성을 분석하고, 유휴 테스트 보드 중 가장 적합한 것을 직접 골라 할당합니다. 정해진 규칙표가 아니라 하드웨어 특성에 대한 모델의 추론으로 판단하기 때문에, 새로운 보드 종류가 추가돼도 코드 수정이 필요 없습니다.

이후 SSH/시리얼 엔진으로 보드에 코드를 배포·실행하고, 에러가 나면 일시적 오류(flaky)인지 회귀 버그인지 LLM이 판정합니다. 결과는 Notion에 기록되고, 이전 대비 정확도가 기준 이상 떨어지면 파이프라인을 실패 처리해 병합을 막습니다. 자연어 챗봇·대시보드로 실험 기록 조회와 보고서(.docx) 생성도 가능합니다.

Python · OpenAI API · GitHub Actions (self-hosted) · Notion API · SSH
